DES form — console script kit

Copy each block, paste it into the browser console on the DES form page, press Enter. Work through them in order and stop as soon as the comma is gone.

FIRST

Open the console

  1. On the DES form page press F12 (or Ctrl+Shift+J) and click the Console tab.
  2. Chrome blocks the first paste for safety. If it refuses, type allow pasting into the console, press Enter, then paste normally.
  3. If the field sits inside an embedded ID.me frame, use the frame dropdown at the top of the console (it reads top) and switch to that frame first.

Rewrite the data attribute and unlock the field

    
Strips the comma out of every data attribute, removes the disabled state, sets the visible value through the native setter so a framework can't discard it, and cleans any hidden input carrying the same string. Re-run script 2 afterward to confirm nothing snapped back.

Patch the request on its way out

    
The reliable one. It edits the outgoing payload after the page has built it, so it works no matter where the value was stored. Run it before clicking submit and watch for the confirmation line in the console. Handles plain bodies, JSON, and FormData.
