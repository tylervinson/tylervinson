Installation Steps
1

Download and extract the ZIP

Click the download button above. Save it somewhere stable — Chrome references the folder by its path on disk after loading, so a location like Documents/extensions/site-audit/ works well.

Extract the ZIP. manifest.json should sit at the root of the extracted folder, alongside the other files.

Unzipped folder
site-audit-extension/
├─ manifest.json
├─ background.js
├─ content.js
├─ dashboard.html
├─ sidepanel.html
├─ …
└─ icons/
2

Open chrome://extensions and enable Developer mode

Type chrome://extensions into the address bar, or Chrome menu → More tools → Extensions.

Toggle Developer mode in the top right. Three buttons appear: Load unpacked, Pack extension, Update.

chrome://extensions
Extensions
Developer mode
Load unpacked
Pack extension
3

Load unpacked

Click Load unpacked and select the extracted folder (the one containing manifest.json, not its parent).

The extension card appears immediately — no restart needed.

AZ Blue Site Audit
Loaded successfully
4

Set the access key

Open the file called config.js in the folder you just extracted — any text editor works. Find the line that says ACCESS_KEY and replace CHANGE_ME with the access key you were given. Save the file, then click the reload icon on the extension card in chrome://extensions.

Without this the tool installs but can't load any data — the side panel will tell you it isn't configured. If you don't have the key, ask whoever set up the tool.

config.js
window.AUDIT_CONFIG = {
ACCESS_KEY: '…your key…',
STATE_URL: …
};
5

Pin it and pick a role

Click the puzzle-piece icon in Chrome's toolbar and pin AZ Blue Site Audit so it's always visible.

Click the icon and choose Admin or Author. See Using the Extension for what comes next.

Pinned to the toolbar
⚠ Don’t move the folder after loading it. Chrome stores the path and will disable the extension if the folder is relocated or deleted — re-load it from the new path if you ever move it.
Developer mode must stay enabled for the extension to keep working. Chrome will occasionally show a banner about developer extensions being active — that’s expected for load-unpacked installs.
