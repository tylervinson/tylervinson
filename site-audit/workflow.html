The Full Loop

Five phases, most of which you skip most days

The first two phases are occasional — you're usually landing on Phase 3 or 4. Content authors mostly live in Phase 4 and 5.

Phase 1

Sign in

Once per browser, in the dashboard. The passphrase is shared with the side panel automatically — sign in once, both surfaces work.

  • Click the toolbar icon
  • Pick Admin or Author
  • Enter the passphrase
Phase 2

Run an audit

Discover pages from the sitemap (or load a saved list), set English-only exclusions, then run.

  • Audit Settings tab
  • Discover / review pages
  • Run new audit
Phase 3

Publish

A run is local until published. Publishing is what the side panel, Power BI, and your teammates actually see.

  • Admin dashboard
  • Publish run to team
Phase 4

Review

Either the dashboard's findings tables, or click Review on site to open azblue.com with the side panel docked.

  • Browse page by page
  • Panel shows that page's findings
  • Expand to highlight on the page
Phase 5

Triage & export

Mark findings done from either surface. Pull the run into Power BI; new 404s post to Teams automatically.

  • Mark done / ignore
  • Power BI refresh (auto or CSV)
  • Teams alert on new 404s

Nothing here is one-way. Triage in the panel updates the dashboard's counts on next load, and vice versa — both read the same published run and the same triage store.

Two Ways In

Dashboard-first vs. panel-first

Same data, two entry points depending on what you're doing.

Starting from the dashboard

  • Click the toolbar icon
  • Scan Top Problem Pages / Findings tables
  • Click "Review on site" to jump into a page with the panel
  • Good for: triage sweeps, running audits, Power BI setup

Starting from the site

  • Browse azblue.com normally, panel stays docked
  • Panel updates as you navigate between pages
  • Expand a finding → it's highlighted right there
  • Good for: page-by-page content review, spot checks

Same shared state

Both paths read the same published run and write to the same triage store. Nothing you do in one is invisible to the other.
