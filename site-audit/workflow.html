The Full Loop

Five phases, most of which you skip most days

The first two phases are occasional — you're usually landing on Phase 3 or 4. Content authors mostly live in Phase 4 and 5.

Phase 1

Pick a role

No passphrase. Choose Admin or Author on first load — Admins can run audits and change settings, Authors see findings only.

  • Click the toolbar icon
  • Pick Admin or Author
  • Continue
Phase 2

Run an audit

Discover pages from the sitemap (or load a saved list), set English-only exclusions, then run.

  • Audit Settings tab
  • Discover / review pages
  • Run new audit
Phase 3

Publish

A run is local until published. Publishing is what the side panel, Power BI, and your teammates actually see.

  • Admin dashboard
  • Publish run to team
Phase 4

Review

Either the dashboard's findings tables, or click Review on site to open azblue.com with the side panel docked.

  • Browse page by page
  • Panel shows that page's findings
  • Expand to highlight on the page
Phase 5

Triage & export

Mark findings done from either surface. Pull the run into Power BI; new 404s post to Teams automatically.

  • Mark done / ignore
  • Power BI refresh (auto or CSV)
  • Teams alert on new 404s

Nothing here is one-way. Triage in the panel updates the dashboard's counts on next load, and vice versa — both read the same published run and the same triage store.

The extension's toolbar icon always opens the dashboard — it never opens the panel directly. There's exactly one built-in way to open the panel, plus one Chrome-native way most people won't stumble onto.

"Review on site" (the documented way)

  • Click the toolbar icon → dashboard opens
  • Click "Review on site" on any dashboard page
  • Opens azblue.com and docks the panel in one action

Chrome's side panel icon (native, optional)

  • The panel becomes available the moment you're on azblue.com — the dashboard doesn't need to be open
  • Click Chrome's own side panel icon in the toolbar, separate from ours
  • Pick "AZ Blue Site Audit" from the list Chrome shows you

Once open, it follows you

However it got opened, the panel is docked to the browser window — not one tab. Navigate anywhere on azblue.com and it updates to that page automatically, until you close it.
