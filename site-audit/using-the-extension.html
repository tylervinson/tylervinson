Getting In

Two doors, one sign-in

1

Open the dashboard

Click the toolbar icon. If the dashboard is already open in a tab, it’s focused instead of duplicated.

Sign in once with the shared passphrase. This also hands the credential to the side panel — you won’t be asked again there.

AZ Blue Site Audit
Click the icon → dashboard opens in a new tab
2

Jump into review mode

From any dashboard page, click Review on site. It opens azblue.com and docks the side panel in one action.

This has to be a real click — Chrome won’t let an extension open the panel on its own.

4

Expand to highlight

Click a finding to expand it. If the audit captured a locatable element — a broken link, placeholder text, a heading — the panel scrolls the page to it and outlines it in gold.

Some findings (meta description, title, canonical) have no visible element on the page. The panel says so rather than pretending.
