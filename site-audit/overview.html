What This Is

The audit tool, without a hosted URL

The Multilingual Site Audit tool used to live at a web address someone had to host, secure, and keep internal. As a Chrome extension, it ships as files inside the browser instead — no domain, no server, nothing publicly reachable. It only runs for people who've installed it.

It has two surfaces. The dashboard is the tool you already know — findings, coverage, triage, Power BI export — now opened from the toolbar instead of a bookmark. The side panel is new: dock it beside azblue.com and it shows findings for whatever page you're looking at, live.

Both read and write the same shared state, so triage done in one shows up in the other, and in the Power BI export.

Core Capabilities

What it does

The audit logic hasn't changed — this is a delivery change, plus a genuinely new way to review findings.

Full Dashboard

Admin overview, Authors board, Audit Settings, and Power BI import instructions — opened as a tab from the toolbar icon.

Per-Page Side Panel

Docks beside the browser and follows you as you navigate azblue.com, scoped to whatever page is active.

Highlight on Page

Expand a finding and the panel scrolls to and outlines the actual element on the live page — the broken link, the heading, the placeholder text.

Shared Triage

Mark a finding done from the panel or the dashboard — it's the same shared store either way, no separate silo.

Power BI Export

Live web-query URLs or CSV downloads for findings, broken pages, coverage, and stale content — documented in-app.

Teams Alerts

The scheduled 404 monitor posts one alert per completed scan to a Teams channel — no email server required.

Architecture

Three pieces, one shared state

The extension is the client. The audit logic and the state it reads and writes live outside it, in a small Cloudflare Worker — the same one whether you're on the dashboard tab or the side panel.

Extension

Dashboard tab + side panel, packaged as a Manifest V3 Chrome extension. Fetches azblue.com pages directly — no CORS proxy needed once installed.

State Worker

Cloudflare Worker holding triage marks, published runs, sitemap 404 history, and the Power BI export endpoint. audit-state

Downstream

Published runs feed Power BI (live URLs or CSV) and a scheduled 404 scan posts new breakages to Teams.
